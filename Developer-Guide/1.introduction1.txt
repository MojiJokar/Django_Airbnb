install Node.js
To install Node.js on Windows:

Go to the official Node.js website:
Node.js Downloads
Download the LTS (Long Term Support) version for Windows.
Run the downloaded .msi installer.
In the setup wizard:
Click Next through the prompts.
Accept the license agreement.
Keep the default installation options.
Make sure Add to PATH remains enabled.
Click Install and complete the setup.
Close and reopen PowerShell, then verify the installation:
